# 爆款标题 + 30秒脚本生成器（离线版）

> 抖音 / 小红书 / 视频号 创作者的选题神器：**一行命令，5 秒出 10 个爆款标题 + 一条 30 秒成片脚本。**
> 不联网、不调任何 API、零依赖、纯 Python 标准库，**双击即用**。

做短视频最费时间的不是拍，是「想标题、写脚本」。这个工具把最机械的一步自动化：
输入一个主题（比如「减脂餐」「副业赚钱」），立刻给你一排可直接用的候选标题，和一条结构完整的口播脚本（黄金3秒→痛点→方法→结果→引导）。

---

## ✨ 特性

- **零依赖**：只用 Python 3 标准库，不用 `pip install` 任何东西
- **完全离线**：不联网、不上传数据，本地一键出稿
- **三平台适配**：抖音 / 小红书 / 视频号，语气自动微调
- **结构化学脚本**：30 秒成片按「黄金3秒→痛点→方法→结果→引导」五段式生成，新手也能直接照读
- **可导出**：加 `--out 草稿.md` 一键存成文档，改完就能发

## 🚀 快速开始

```bash
# 需要 Python 3（一般系统自带），无需安装任何依赖
python title_generator.py --topic "考研英语" --platform douyin
python title_generator.py --topic "减脂餐" --platform xiaohongshu --count 8
python title_generator.py --topic "副业赚钱" --out 草稿.md
```

| 参数 | 说明 | 默认值 |
|------|------|--------|
| `--topic` | 内容主题，必填，如「考研英语」「减脂餐」 | — |
| `--platform` | 目标平台：`douyin` / `xiaohongshu` / `shipinhao` | `douyin` |
| `--count` | 生成标题数量 | `10` |
| `--out` | 可选，把结果写成 `.md` 文件 | 不写则只打印 |

## 📋 真实输出示例

```text
《副业赚钱》· 小红书 爆款草稿

【候选标题】
  1. 别再硬背了，副业赚钱其实靠底层逻辑
  2. 我赌你不知道，副业赚钱的正确顺序才是关键
  3. 3个被低估的副业赚钱技巧，第2个绝了
  4. 副业赚钱做到这1点，效果直接翻倍
  5. 为什么有人副业赚钱事半功倍？答案在这
  6. 千万别硬撑副业赚钱，90%的人都踩坑

【30秒脚本】
  · 0-3s 黄金开头：“副业赚钱这件事，90%的人都做反了。”
  · 3-12s 痛点共鸣：“你是不是也瞎练副业赚钱，花了时间却没结果？”
  · 12-22s 给方法：“记住一个核心：关键节奏。比如先__再做__，顺序对了就顺了。”
  · 22-28s 晒结果：“照这个思路，副业赚钱效率直接提上来，不用再无效努力。”
  · 28-30s 引导互动：“觉得有用点个赞，主页还有更多副业赚钱干货。”
```

> 标题由精选高频钩子模板 + 主题组合而成（非随机乱拼），脚本按短视频黄金结构生成。生成后**按需改写**即可发布，建议加入你自己的真实案例，效果更佳。
